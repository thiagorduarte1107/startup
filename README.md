# Kit Software House Brasil 🇧🇷
### Framework Operacional, Jurídico e Comercial para Boutiques de Software e Sustentação de Sistemas

> **Um toolkit open-source em Markdown pronto para empresas de tecnologia, software houses e consultorias no Brasil.**  
> 100% amparado na legislação brasileira: **Código Civil (Lei 10.406/02)**, **Lei do Software (Lei 9.609/98)**, **LGPD (Lei 13.709/18)** e **Marco Civil da Internet (Lei 12.965/14)**.

---

## 🎯 Por Que Este Repositório Existe?

A maioria dos contratos e playbooks disponíveis no GitHub são traduções de modelos norte-americanos (Delaware/Califórnia), que não possuem validade jurídica ou não protegem desenvolvedores de tecnologia no Brasil.

Este repositório fornece a esteira completa para operar uma empresa de desenvolvimento e manutenção contínua de software com alta rentabilidade, faturamento recorrente (MRR) e segurança jurídica.

## ⚖️ Conformidade Legal Brasileira

* **Lei do Software (Lei nº 9.609/1998):** Propriedade intelectual do código vinculada à quitação financeira integral.
* **Código Civil Brasileiro (Lei nº 10.406/2002):** Prestação de serviços PJ, regras de horas não cumulativas, mora e rescisão com aviso prévio.
* **Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD):** Contratada atuando estritamente como **Operadora** e o cliente como **Controlador**.
* **Marco Civil da Internet (Lei nº 12.965/2014):** Padrões de guarda de registros de acesso a aplicações (Art. 15).
* **Assinatura Eletrônica (Lei nº 14.063/2020):** Validade jurídica para assinaturas digitais (Gov.br, ZapSign, ClickSign).

## 🚀 Como Utilizar

1. Faça um Fork ou Clone deste repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/kit-software-house-brasil.git
   ```
2. Abra a pasta `operacoes/` no seu editor (VS Code, Obsidian, etc.);
3. Substitua as tags `[RAZÃO SOCIAL]` e `[CNPJ]` pelos dados oficiais da sua empresa;
4. Utilize a [PROPOSTA_COMERCIAL_EXECUTIVA.md](operacoes/02_comercial_marketing/PROPOSTA_COMERCIAL_EXECUTIVA.md) e o [CONTRATO_SUSTENTACAO_E_SLA.md](operacoes/01_juridico/CONTRATO_SUSTENTACAO_E_SLA.md) para fechar seus primeiros contratos com segurança.
